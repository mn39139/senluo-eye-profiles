场景一：钉钉组织架构与ERP/MES系统集成

打通组织主数据，实现人员一处维护、三处生效

集成方案

1. 组织主数据统一
钉钉作为组织架构主数据源，通过钉钉连接平台官方"金蝶云·星空"连接器同步部门/人员/岗位至金蝶；维尔斯MES通过API接收工号、班组、岗位权限
2. 双向同步机制
钉钉事件订阅：人员入职/离职/调岗自动推送至金蝶云·星空和维尔斯MES；金蝶部门变更反向同步至钉钉（基于轻易云/钉钉连接平台）
3. 角色权限映射
钉钉角色（如"采购员"）→ 金蝶云·星空角色（采购订单录入）→ 维尔斯MES角色（领料权限），三系统权限一键开通
4. 海外组织隔离
越南/印尼工厂作为独立"子公司"挂在钉钉组织树下，金蝶云·星空多组织架构天然支持，数据权限隔离，但纳入总部管理视图

场景二：费用/采购/付款申请与ERP对接

审批流自动生成ERP凭证，实现业财一体化

三大单据对接方案

1. 费用申请 → ERP费用凭证
钉钉费用申请单（差旅/招待/办公）审批通过后，通过钉钉连接平台官方连接器自动生成金蝶云·星空费用凭证，关联部门/项目/预算
2. 采购申请 → ERP采购订单
钉钉采购申请单（物料/服务）审批通过后，自动调用金蝶"采购申请暂存"接口创建采购订单，关联供应商/物料/BOM
3. 付款申请 → ERP付款单
钉钉付款申请单审批通过后，自动生成金蝶云·星空付款单，三单匹配（订单/收货/发票）自动核验
4. 预算控制前置
钉钉审批时实时查询金蝶云·星空预算余额，超预算自动拦截；预算执行情况钉钉仪表盘可视化

场景三：钉钉考勤与工资核算一体化

考勤数据自动汇总，对接工资核算，多工厂统一管理

考勤工资一体化方案

1. 多工厂考勤规则配置
国内工厂（标准工时/综合工时）、越南工厂（当地劳动法）、印尼工厂（当地劳动法）独立配置考勤组
2. 考勤方式多元化
办公室：钉钉GPS+WIFI打卡；车间：钉钉人脸识别打卡；外勤：钉钉定位打卡
3. 加班/请假/调休自动核算
审批通过后自动计入考勤汇总，按规则换算加班费/调休额度，避免人工统计错误
4. 工资核算自动化
考勤数据自动推送至工资核算模块，结合基本工资+绩效+加班+扣款，一键生成工资单；可对接金蝶云·星空薪酬模块
5. 工资条推送
工资单通过钉钉工作通知推送给员工，支持电子签收，海外员工本地语言展示
